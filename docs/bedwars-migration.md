# BedWars map configuration

The source has two separate selectors: seven map layouts and eight rule modes. In `game.yml`, set `mode` to one rule mode (`normal`, `no-beds`, `unlocked`, `xp`, `double-resources`, `class`, `zombie-wave`, or `permanent-bed`). The `source-rule-modes` table records its source selector number. Map selection is independent: use the matching `locations.yml` arena name (`mogu`, `unnamed`, `space`, `special1`, `glassworld`, `siheyuan`, or `shenjing`) when joining, for example `/party join bedwars mogu`. `arena_1` remains the generic template.

The source selector's map names map as follows: 1 `mogu` (蘑菇岛), 2 `unnamed` (一枝花), 3 `space` (奇怪的环保太空船), 4 `special1` (迷途岛), 5 `glassworld` (玻璃世界), 6 `siheyuan` (四合院), and 7 `shenjing` (樱花木船). Each named entry currently aliases the blank `arena_1` template. Before configuring a map, replace that alias with its own copy of the template so the maps can have independent coordinates. All coordinates are intentionally unset; no source-world coordinates were carried over.

For each map, configure `bounds`, `regions.build`, the waiting/spectator/exit points, enough general spawns for `players.max`, team spawns, two adjacent bed blocks per active team, iron and gold generators per active team, diamond and emerald generators, shop points, and exactly one `points.groups.wither-spawn` point. BedWars validation rejects an empty wither point group. The final event runs at 31:00 by default and spawns one wither for each team that still has players at that configured point. In `zombie-wave` mode the source summons five zombies at every bed marker, including destroyed beds; the migration uses each configured bed group as its base. Configure all four bed groups to preserve the four-marker wave, even when only two teams are active.

The original `after_loaded_start_reset` function clones each selected map from a separate `airworld` layout. This plugin instead snapshots and restores the selected arena in its configured world, so each layout must already exist in the target world before play. The existing party join command accepts a specific arena name; it has no random-map selector. Select a map explicitly by its name. The source rule mode is static in `game.yml` for each deployment.
