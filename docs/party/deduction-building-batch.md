## 建图要求

所有地图先填写 bounds 两角、world、waiting/spectator/exit 和至少 players.max 个独立 spawns，确认后才改 configured:true。不要使用源地图绝对坐标。

- 方块躲猫猫：`hunter-hold` 猎人等待室、`hunter-spawns` 猎人出动/复活点、`decoys` 背景假方块候选点，均在界内。按新场景填伪装方块白名单；原地图自定义 stainglass/concrete 等标签已展开，concrete_powders 拼写转为目标版本 concrete_powder。
- 密室杀手：`gold-spawns` 安全金币点；`potion-shops` 放真实炼药锅的方块坐标；`wind-shops` 风弹交易点击块坐标。`regions.shops` 必须包含所有炼药锅，以恢复全部变更。
- 吸血鬼之夜：`loot-spawns` 安全掉落点。地图需要真实遮阳处；日光检测沿用原生天空光值。个人昼夜只影响本局玩家显示。
- 两个建筑游戏：`regions.build` 为允许建造/破坏并每轮清为空气的体积；起点地板放在体积以外，避免清掉。`builder` 与 `runners` 分组各放起点；观战点宜在bounds内的安全高度。你建我跑自建终点为粉色羊毛，不要在起点放这种材料；原红色底板可留在 build 体积下方。所有跑酷构件含水半砖、结构空位邻格必须在建造体积内。
- 美食派对：配置 `collect-<食材 ID>` 点位组（每点放干草块）、`station-oven/grill/prep/mix`（分别放 game.yml 中配置的炉子、营火、工作台、酿造台方块）、`delivery`（放配置的木桶）以及至少16个不重叠玩家出生点。订单与食材库存按玩家独立；每次交付在订单有效期内匹配，错单不会扣除食材或成品。不要在等待区外设置可被交互的箱子来替代收货点。
- 拆弹专家：新建 `regions.level-1` 至 `level-6` 六个独立关卡，`level-starts` 严格按顺序填六个起点。关卡可采用原17×17×5尺寸或其他小体积，每关最多10000方块；其最低层至少有一个尖啸体及一个传感器，成功和羊毛扣分均只统计该最低层，勿放装饰幽匿。六关总快照不能超过配置上限。传感器和尖啸体必须允许原生振动触发。初始关卡原位快照替代源地图异地克隆模板，每个玩家得到同一原始关卡。
